PrivyScan

Built at HackPrix Season 2

An offline privacy scanner that reads source code and reports secrets and personal data before they get pushed or shared.

  • Detects API keys, passwords, tokens and personal data using Python AST analysis and regex scanning.
  • Supports Python, JavaScript, Java, Go, C/C++, JSON, .env and YAML files.

  • Interactive dashboard for reviewing results. Built with Flask, Bootstrap and custom CSS.
